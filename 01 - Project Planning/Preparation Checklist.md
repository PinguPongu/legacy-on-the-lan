Suggested sequence; “days” are work blocks, not fixed deadlines.

## Day 1 — Research design

- [x] Review [[Project Overview]] against the proposal.
- [x] Agree on three testable hypotheses in [[Dark Arts/Legacy on the Lan/01 - Project Planning/Research Design]].
- [x] Identify independent, dependent, controlled, and confounding variables.
- [x] Define metrics, counting rules, and event categories.
- [x] Choose observation duration, repeat count, and comparison procedures.
- [x] Review [[Experiment Template]] for consistent documentation.

## Day 2 — Infrastructure planning

- [ ] Draw the actual topology in [[Lab Plan]].
- [x] Confirm required VMs, OS versions, resources, and installation sources.
- [ ] Resolve Frostbyte questions about exposure, NAT, filtering, and capture access.
- [ ] Document authorization, isolation, outbound restrictions, stop conditions, and recovery.
- [ ] Define each phase's configuration and how changes will be recorded.

## Day 3 — Monitoring preparation

- [ ] Study tools and background topics in [[Literature and Technical Research]].
- [ ] Confirm capture location and log coverage for every endpoint.
- [ ] Verify clock synchronization and timestamps.
- [ ] Set evidence naming, storage, retention, and backup rules in [[Evidence Register]].
- [ ] Prepare repeatable scan, capture, and log collection procedures.

## Day 4 — Pilot and readiness

- [ ] Finalize [[Phase 1 - Baseline Plan]].
- [ ] Document snapshot and restoration steps.
- [ ] Run authorized controlled connectivity tests to verify monitoring.
- [ ] Confirm test traffic appears in captures and relevant logs.
- [ ] Check capture loss, disk capacity, timestamps, and evidence links.
- [ ] Restore the starting state and record pilot corrections.

## Gate before official experiments

- [ ] Methodology and observation windows agreed.
- [ ] Authorization and containment verified and documented.
- [ ] VM configurations and recoverable snapshots recorded.
- [ ] Monitoring validated with linked pilot evidence.
- [ ] Stop and recovery procedures verified.
- [ ] Remaining limitations recorded and readiness decision entered in [[Research Journal]].

## After preparation

- [ ] Execute each phase using [[Experiment Template]].
- [ ] Register evidence and record deviations after every run.
- [ ] Compare results using [[Analysis Plan]].
- [ ] Write and review the report using [[Report Outline]].
