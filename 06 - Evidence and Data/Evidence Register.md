# Evidence Register

## Proposed storage convention

Create a folder for each run under `06 - Evidence and Data`, using a unique ID such as `P1-R01`. Keep captures, scan output, logs, configuration exports, and checksums together. Use timestamps in UTC.

Example filename: `P1-R01_YYYYMMDDTHHMMSSZ_host_artifact.ext`.

- [ ] Confirm naming and backup/retention rules before the pilot.
- [ ] Preserve raw files; store derived files separately and document transformations.
- [ ] Record collection tool/version, settings, vantage point, and time window.
- [ ] Generate checksums when evidence is collected or transferred.
- [ ] Link every finding to the relevant evidence and experiment.
